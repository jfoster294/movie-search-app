Simple rules

What it can do

It can read the folder you choose, list real video files, calculate real sizes, show real relative paths, infer quality from filenames, track status, and export the scan as CSV.

What it cannot do

A GitHub Pages website cannot automatically scan all connected drives without your permission. You must select the folder each time you want to refresh a drive bay.
