Help

What this app can and cannot do

What it can do

It can scan the folder you choose, read real file names, calculate real file sizes, show real paths, infer quality from filenames, and save the scanned metadata locally.

What it cannot do

A browser website cannot automatically scan every drive on your computer without permission. You must select the folder each time you want to refresh the current state.
