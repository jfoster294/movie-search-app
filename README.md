# Movie Search App

A front-end movie search app where users can search movies and view movie information using an API.

## Live Demo

Coming soon

## Features

- Search for movies, series, and episodes
- Filter results by type
- View movie posters
- View movie title, year, and type
- Click a movie to view more details
- View plot, genre, actors, director, rating, runtime, and release date
- Saves the last search with local storage
- Responsive design for mobile and desktop

## Built With

- HTML
- CSS
- JavaScript
- OMDb API
- Local Storage

## Project Goal

This project was built as part of my front-end developer portfolio to practice API fetching, DOM manipulation, search forms, filtering, local storage, and responsive design.
