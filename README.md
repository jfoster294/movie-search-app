# Cinema Library

A Plex-inspired cinema storage dashboard where users can manage movies across NAS drives, external SSDs, archive drives, and home media storage.

## Live Demo

https://jfoster294.github.io/movie-search-app/

## Features

- Starter movie library included
- Add movies manually
- Choose from sample movie titles
- Assign movies to storage drives
- Track movie quality: 720p, 1080p, 4K, and 8K
- Add file size in GB
- Track watch status: Not Watched, Watching, and Watched
- Mark movies as favorites
- Remove movies from the library
- View movie details
- Search the library
- Filter by storage drive
- Filter by quality
- Filter by watch status
- Sort by newest, title, or file size
- View storage usage by drive
- View total movies and total storage used
- Recent activity log
- Saves everything with local storage
- Responsive design for desktop and mobile

## Storage Drives

The app includes four example storage drives:

- NAS Drive 1
- NAS Drive 2
- External SSD
- Archive Drive

Storage usage is calculated from the movies saved in the library.
